
# Real State Project

This is a frontend part of realstate project.


## Environment Variables

To run this project, you will need to add the following environment variables to your .env.local file in the project root.






`NEXT_PUBLIC_API_BASE_URL=http://imovel.eu-central-1.elasticbeanstalk.com/imovel/api`

`NEXT_PUBLIC_NODE_ENV=development`


## Run Locally

Clone the project

```bash
   git clone https://github.com/kintwadi/realstate_front_end.git
```

Go to the project directory

```bash
  cd realstate_front_end
```

Install dependencies

```bash
  pnpm install
```

Start the server

```bash
  pnpm run dev
```


## Tech Stack

I built this project using Node v20. To make sure everything runs smoothly, I recommend installing Node v20. Thanks for your understanding!




**Client:** Nextjs15, TailwindCSS, ShadCN
